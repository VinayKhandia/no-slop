# No-Slop Start

Client-driven gate workflow kickoff for new websites, landing pages, 3D/animated sites, and apps.

1. Immediately load skills/client-collab and follow its Gates 0 to 6 exactly. Pause at every gate and ask the client; no building before Gate 0 is approved.
2. Read DECISIONS.md at the start of every turn; record each decision there.
3. Skill order: prompt-optimizer (BRIEF), client-collab, asset-intake, reference-teardown, design-taste, storyboard, motion-craft, scene-3d, visual-qa, reviewer.
4. Use the client's photos and models; never report done without viewing screenshots; sub-agents only after Gate 3.
5. Autopilot only if the user types the literal word "autopilot".
6. Pause wording: use the tool's ask-user tool if it exists, otherwise ask in chat and end the turn.
